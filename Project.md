# Excel-Project
Annual Sales Report Dashboard

Project Overview:
This project is an interactive Excel dashboard created for analyzing the annual sales performance of Vrinda Store for the year 2022. The dashboard helps in tracking sales, orders, customer demographics, order status, top-performing states, and sales channels in a visual and easy-to-understand format.

# Dataset-Used
<a href= "https://github.com/Abhi283-2/Excel-Project/blob/main/Vrinda%20Store%20Annual%20Sales%20Report.xlsx">Dataset-value</a>

Key Features:
Monthly Orders vs Sales Analysis
Men vs Women Sales Comparison
Order Status Tracking (Delivered, Returned, Cancelled, Refunded)
Top 5 States by Sales
Age & Gender-wise Order Analysis
Channel-wise Order Distribution (Amazon, Myntra, Flipkart, etc.)
Interactive Filters using Slicers for better data analysis
